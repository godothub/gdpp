# GDPP

GDPP：Godot GDScript AOT & Extension
> Compile your GDScript project into binaries, with no source code included in exported builds.

- Ultra-High Performance: As fast as C/C++
- Easy to Use: One-click export after enabling the plugin
- Automatic Encryption: Protect your assets as much as possible
- Syntax Extensions: A more powerful GDScript language
- Cross-Platform: Available on all platforms supported by Godot
